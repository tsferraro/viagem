# entregas/

Documentos gerados pela skill **destination-scout** (levantamentos de destino), **versionados**.

- Cada entrega: a **fonte `.md`** + o **`.pdf` final**, com nome descritivo por destino (ex: `notre-dame-domingo-jun2026.md` / `.pdf`).
- O `.docx` é só intermediário da conversão `md → docx → pdf` — **não versionado** (ignorado pelo `.gitignore`).
- Regenerar/editar: mexa no `.md` e rode os scripts em `skills/destination-scout/scripts/` (ver `SKILL.md` PASSO 5).
- Pasta **reservada** (não é uma "viagem" — `regen-landing.py` a ignora).
